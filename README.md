# 📖 VRCX Memory Book | VRChat 专属回忆档案馆

🐖os：因为VRCX的视图我感觉不好看，就写了这个网站，没有exe程序的版本，我们没有打包，你只需要直挂“网站链接”在电脑是就可以了

> “数据留在本地，回忆珍藏心里。”

这是一个完全免费、开源的 VRChat 社交回忆可视化工具。只需拖入你的 VRCX 数据库（`.sqlite3`），即可生成高颜值的同框热力图、好友回忆档案、以及你的专属“时间胶囊”。

## ✨ 核心特性

- 🔒 **绝对隐私与安全**：本工具为 **100% 纯前端、纯本地运行**。没有任何后端服务器，您的数据库文件绝不会被上传到任何地方。连作者也无法查看您的数据。
- 🎨 **现代暗黑 UI**：极简毛玻璃质感、呼吸光晕、专属 Emoji 时间线，拒绝枯燥的数据表格。
- 💾 **本地加密保险箱**：支持一键导出 `.vrcxmem` 加密备份文件，换电脑也能随时恢复所有回忆。
- 🚀 **丝滑拖拽**：支持直接拖拽 `VRCX.sqlite3` 数据库或 `.vrcxmem` 备份文件到网页中，瞬间解析。

## 🚀 如何使用？

1. **获取数据**：在您的电脑上找到 VRCX 数据库文件（通常位于 `%AppData%\VRCX\VRCX.sqlite3`）。
2. **拖入解析**：打开本工具网页，将文件拖入页面。
3. **查看回忆**：点击热力图上的好友，查看你们的专属同框档案。
4. **本地备份**：点击【导出加密备份】，妥善保存您的 `.vrcxmem` 文件。
